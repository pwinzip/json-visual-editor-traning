# Matt Pocock's skills (vendored)

The 27 skills in this folder (everything except this README and the LICENSE file) are copied from
[mattpocock/skills](https://github.com/mattpocock/skills) at commit
`abeeaf95660ba9e8b7c753eb38f441ca707a8823` (plugin version 1.3.2), MIT licensed
(see `LICENSE-mattpocock-skills`). They are the same set the official
`mattpocock-skills` Claude Code plugin ships.

They are committed here so anyone who opens this repo in Claude Code gets them
without installing anything. They do not update themselves: to update, copy the
skill folders again from a newer commit of the upstream repo.

Do not also install the `mattpocock-skills` plugin on your account, or every
skill will appear twice.

First run in this repo: `/setup-matt-pocock-skills` (issue tracker, triage labels, domain docs).
